# La documentation d'Unicorn-Radio

Sur le modèle d'Unicorn-TV : un dossier par usage, un fichier par chantier.

- `CHANGELOG.md` : l'historique, une entrée par chantier, la plus récente en
  tête.
- `ROADMAP.md` : ce qui reste à faire, ce qui a été décidé, ce qui a été
  écarté et pourquoi.
- `format-d-echange.md` : le fichier JSON que l'application partage avec
  Unicorn-TV. **Fait foi pour les deux projets.**
- `correctifs/NNN-titre.md` : un chantier, numéroté à la suite, avec ce qu'il
  y avait, ce qui est fait, les fichiers, la vérification.
- `analyses/AAAA-MM-JJ-titre.md` : une réflexion avant de coder, quand le
  chantier le mérite.
- `notes-de-version/X.Y.Z.txt` : la note de chaque version, FR puis EN,
  écrite pour qui utilise l'application.
- `prompts/publier.md` : la procédure de publication, pas à pas.
- `prompts/demarrer.md` : le prompt qui a ouvert la première session de
  travail, à relire pour en ouvrir une autre.
